## 🚨 Известные проблемы

### 1. **Конфликт портов**
```
Error: listen EADDRINUSE: address already in use :::3050
```
**Решение:** Остановить сервер перед тестами или использовать другой порт

### 2. **Блокировка файла БД**
```
EBUSY: resource busy or locked, unlink 'test-cortex.db'
```
**Решение:** Правильно закрывать соединения с БД в afterAll

### 3. **Кеширование модулей**
```
STORAGE_TYPE не меняется между тестами
```
**Решение:** Очищать require.cache или использовать отдельные процессы
